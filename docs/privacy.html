Privacy Policy

Effective: November 17, 2026 · Controller: Jenn Royleance · Contact: jenn.rae.ross@gmail.com

Short version

Ariadne is an offline-first desktop writing app. There are no accounts, no ads, no analytics, and no tracking on this website or in the app. Your writing stays on your device unless you turn on sync to your own cloud storage.

What the app stores locally

  • Your library (library.json), window geometry, custom themes, and export styles in the OS app-data folder (com.craft-anything.ariadne).
  • Spelling/grammar checking runs fully on-device. Text is never sent to a server for checking.
  • Environment-variable overrides (ARIADNE_LIBRARY_PATH, etc.) only change where files live; they never transmit data.

Optional sync (off by default)

  • iCloud Drive (Mac): if you move the iCloud section to iCloud Drive under Settings → Sync, the app mirrors those groups as folders and .md files in your own iCloud Drive. Apple handles that storage under Apple's terms.
  • Google Drive (all platforms): if you connect Google Drive, the app syncs those groups to an Ariadne folder in your own My Drive. Sign-in uses a standard OAuth flow in your browser; tokens are kept in your OS keychain. The app only accesses the files it creates for sync.
  • Sync mirrors are human-readable folders plus .md files; the local JSON store remains the source of truth. Conflict copies are kept for your review and never uploaded anywhere else.

Update checks

The app checks the public GitHub Releases feed for this repository about once a day (plus a manual “Check for updates”), to show release notes and a download link. You can turn checks off in Settings → Updates. Like any web request, this exposes standard network metadata (e.g. IP address) to GitHub.

This website

This site is static HTML and CSS hosted on GitHub Pages. It sets no cookies, runs no analytics, and loads no third-party scripts or fonts. The download buttons query the public GitHub Releases API (api.github.com) to resolve direct asset links; that request goes to GitHub, not to us. Downloads themselves are served by GitHub.

What we never do

  • No accounts, no telemetry, no crash-report uploads, no advertising identifiers.
  • We do not sell personal information and we do not share your writing with anyone — we never receive it.

Your choices

  • Use the app fully offline; skip sync entirely.
  • Disconnect Google Drive or move the iCloud section back to local storage at any time under Settings → Sync.
  • Disable update checks in Settings → Updates.
  • Delete local data by removing the app-data folder (back up any .md export or sync mirror first).

Children

Ariadne has no age gate because it collects nothing, but it is general-purpose software not directed at children.

Changes

If this policy changes, the updated date above will change and the new version will be posted at this URL. Material changes will also be noted in the release notes.
